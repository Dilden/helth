## Build/Lint/Test Commands

### Unit Tests with Vitest

- `npm run test:unit` - Runs unit tests using Vitest
- `vitest` - Run specific file(s) or directory(ies) to test with Vitest

### End-to-End Tests with Playwright

- `npm playwright test` - Runs end-to-end tests using Playwright

### Run All tests with both Playwright and Vitest

- `npm run test`

### Linting

- `npm run lint`

### Format

- `npm run format`

## Naming Conventions

- Use camelCase for function names

## Code Style Guidelines

- Follow Prettier formatting rules
- Make sure to maintain consistent code formatting by running `npm run prettier` after making changes to the code
- This project uses Svelte and SveletKit
